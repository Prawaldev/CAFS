# <img src="https://raw.githubusercontent.com/Prawaldev/CAFS/main/public/icons/info.svg" width="20" height="20" align="center"> About cafs

cafs is a curated index of the best anime, manga, reading, gaming and tool resources on the internet. Every entry is hand-picked and kept up to date.

---

## <img src="https://raw.githubusercontent.com/Prawaldev/CAFS/main/public/icons/info.svg" width="18" height="18" align="center"> What is this?

cafs is an archive and discovery hub, not a search engine. Think of it as a vetted collection: sites are reviewed before they are listed, and entries are trimmed when they stop being useful.

## <img src="https://raw.githubusercontent.com/Prawaldev/CAFS/main/public/icons/star.svg" width="18" height="18" align="center"> How sites are curated

Every site is manually reviewed. Criteria include reliable uptime, active maintenance, genuine utility, and community reputation. Featured entries are marked with a star.

## <img src="https://raw.githubusercontent.com/Prawaldev/CAFS/main/public/icons/settings.svg" width="18" height="18" align="center"> Technical details

- Built with Vite + TypeScript. All content is static Markdown.
- No backend, no database, no authentication, no user accounts.
- Search is powered by Fuse.js and runs entirely in your browser.
- Favorites, history, and notes are stored in localStorage and never sent to a server.
